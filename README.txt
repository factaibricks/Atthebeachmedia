AT THE BEACH MEDIA WEBSITE - STARTER PACKAGE

Files:
- index.html: Home page
- about.html: About
- services.html: Services
- advertisers.html: Advertiser partnerships
- publishers.html: Publisher partnerships
- contact.html: Contact form demo
- privacy.html and terms.html: placeholder legal pages
- assets/style.css: responsive styling
- assets/script.js: mobile menu and copyright year

HOW TO PREVIEW:
Open index.html in a browser.

HOW TO UPLOAD:
Upload all files and the assets folder to your hosting public_html (or the equivalent web root) using your hosting File Manager or FTP.

IMPORTANT BEFORE LAUNCH:
1. Replace the temporary ATB text mark with your original logo.
2. Update contact email and any real business details.
3. The contact form is a demo that opens the visitor's email app; connect a secure form backend/service to receive submissions reliably.
4. Review privacy policy and terms with appropriate legal guidance.
5. Add analytics, cookie/consent tools, SEO metadata, favicon, and any verified company credentials you actually use.
6. Do not publish placeholder statistics, testimonials, or unsupported performance claims.

This is a static HTML/CSS/JS website starter, not a WordPress theme. No build step is required.


HOSTING PROVIDER NOT KNOWN YET:
This website is plain static HTML/CSS/JS, so it can be hosted on most providers.
General steps:
1. Log in to the hosting account where your domain/hosting is managed.
2. Find a section named File Manager, Website Files, Web Root, public_html, or www.
3. Upload the ZIP and extract it into the website's root folder.
4. Make sure index.html is directly inside the root folder (not nested inside an extra folder).
5. Visit your domain and test every page and the mobile menu.
6. If your domain is registered separately, update its DNS records according to the hosting provider's official instructions.
7. Enable HTTPS/SSL from the hosting control panel.

Do not change DNS until you know which hosting account should serve the domain.
